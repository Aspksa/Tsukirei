# Tsukirei / Цукирэй

Локальное персональное ИИ-пространство для Windows с переносимым BAT-запуском и веб-интерфейсом.

## Быстрый запуск

1. Скачайте ZIP проекта: https://github.com/Aspksa/Tsukirei/archive/refs/heads/main.zip
2. Распакуйте на компьютер или внешний M.2 SSD.
3. Дважды нажмите **Tsukirei.bat**. BAT проверит Node.js 22.18+, при необходимости скачает официальный переносимый LTS с проверкой SHA-256, установит зависимости и откроет браузер после ответа сервера.
4. Локальный сайт: **http://127.0.0.1:3000**. Для остановки сервера закройте окно BAT или нажмите Ctrl+C.

Не нужны Docker, администраторские права, Python, HTTPS или локальная ИИ-модель. Требуется Windows PowerShell 5.1 (входит в Windows 10/11). Интернет нужен при первой установке Node.js и при обращениях к Cloud.ru.

**Команды:**
- Tsukirei.bat --diagnose — проверить окружение без установки;
- Tsukirei.bat --no-open — запустить без открытия браузера;
- Tsukirei.bat --help — подсказка.

Если порт 3000 занят, установите TSUKIREI_PORT в окружении перед запуском BAT.

## Реализовано в v0.1

- Главная с интерактивной сферой памяти и реальными счётчиками.
- Память: создание и удаление локальных заметок.
- Дела: создание, завершение и удаление задач.
- Чат: открывается только кнопкой-аватаром, Esc закрывает, Ctrl+K переключает.
- Cloud.ru: сохранение ключа, выбор модели, проверка доступных моделей вручную, настоящие ответы ИИ.
- Агенты: исполнительный движок ещё не добавлен; интерфейс честно показывает ноль запущенных агентов.
- Node.js + TypeScript HTTP API без внешних runtime-зависимостей, интерфейс на нативном JavaScript/CSS.
- Только локальный HTTP-сервер 127.0.0.1, без фоновых запросов Cloud.ru.

## Где хранятся данные

- data/tsukirei.json — заметки, задачи и архив диалогов.
- data/cloudru-settings.json — API-ключ Cloud.ru и модель. Файл исключён из Git. Не передавайте его третьим лицам.
- logs/ — журналы BAT.
- .runtime/ — переносимый Node.js и npm-cache.

Для Cloud.ru используется официальный API https://foundation-models.api.cloud.ru/v1 (Bearer API-ключ). При отправке сообщения Cloud.ru получает его текст и до 12 предыдущих сообщений для контекста; локальные заметки и задачи не отправляются. Проверка списка моделей отправляет ключ только по кнопке. Тарификация API зависит от условий Cloud.ru.

Потоковая генерация ответов, реальные агенты и граф знаний пока не реализованы.

## Разработка и тесты

Команды при установленном Node.js 22.18+:

    npm ci
    npm run check
    npm test
    npm run dev

Если сайт не открывается, запустите BAT с параметром --diagnose и посмотрите файлы в logs/. GitHub Actions запускает тесты API и проверки BAT на Windows, включая кириллицу и специальные символы в пути.
