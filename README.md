# Tsukirei / Цукирэй

Новый персональный ИИ-проект. **Сейчас реализован только запускатор для Windows**; приложения и сайта в репозитории ещё нет.

## Как запускать

1. Скачайте ZIP репозитория с GitHub и распакуйте в любую папку, в том числе на внешний M.2 SSD.
2. Дважды нажмите **`Tsukirei.bat`**. Дополнительные права администратора, Docker и отдельная установка PowerShell не нужны.
3. Пока нет кода приложения, BAT сообщит об этом и оставит окно с сообщением об ошибке открытым.
4. Когда появятся исходники TypeScript/Node.js с `package.json` и командой `dev`, `start` или `preview`, BAT установит зависимости, запустит сервер и откроет сайт **только после успешного ответа HTTP**.

Дополнительные команды:

- `Tsukirei.bat --diagnose` — проверить окружение без скачиваний и запуска;
- `Tsukirei.bat --no-open` — запустить, не открывая браузер;
- `Tsukirei.bat --help` — справка.

**Что уже умеет BAT:** запуск из папок с кириллицей и пробелами; переносимая установка официального Node.js LTS (если нет Node.js 20+); проверка SHA-256 скачанного архива; установка npm-зависимостей в проект; запрет второго запуска; проверка занятого порта; журналы `logs/`; автоматическое открытие локального HTTP-сайта после проверки доступности. Не требуется Docker, глобальная установка зависимостей или HTTPS.

Папки `.runtime/`, `logs/`, `data/`, `node_modules/` и локальные `.env*` не отслеживаются Git. API-ключи Cloud.ru не нужно сохранять в репозитории.

**Важно:** доступность сайта и работа самого приложения будут проверены после добавления его исходников; на этом этапе BAT не может запустить отсутствующий сервер.
